# Missions

A mission is a structured container for a significant project — a career move, a complex
initiative, a stretch goal. See `core/mission-structure.md` for the full schema.

- Start one by copying `_template/` to `missions/<mission-name>/`, or run `/marty-new-mission <name>`.
- Register it in `core/active-config.md` — directory presence alone does not make a mission
  active.
- End one with `/marty-end-mission`, which extracts lasting learnings into `memory/` before archiving
  to `missions/_archive/`.

**Privacy:** everything here except this README and `_template/` is gitignored and stays on
your machine.
