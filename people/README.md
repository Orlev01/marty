# People

Relationship profiles for the people [client] works with repeatedly. One file per person
(`firstname.md` or `firstname-lastname.md`). Marty reads a profile when a situation involves
that person, and updates it as new dynamics emerge.

A useful profile covers: their role and what they optimise for, the current state of the
relationship, what works and what doesn't when communicating with them, and any open dynamics
worth tracking.

**Privacy:** everything in this directory except this README is gitignored. These files are
candid by design — they must never leave your machine. Marty creates them as needed; you can
also write them yourself.
