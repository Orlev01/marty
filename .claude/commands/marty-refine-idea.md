Read the ideas directory at `ideas/` and ask [client] which idea to work on. If there's only one, or if the user specified an idea name, go directly to it.

Read the idea file completely. Then refine it through coaching, not rewriting:

1. **Clarify the core.** What is this idea actually about? Strip it to one sentence. If you can't, the idea has multiple ideas in it — name them.

2. **Stress test.** What's the strongest objection to this idea? What would a sceptic say? What's the failure mode?

3. **Connection.** Does this connect to an active mission, an open thread, or [client]'s values? If so, how? If not, why is [client] thinking about it?

4. **Next action.** What's the smallest thing [client] could do to test or advance this idea? Not a plan — one move.

5. **Refine the file.** Based on the conversation, update the idea file with sharper framing, resolved questions, and the next action. Keep [client]'s original writing — add to it, don't replace it.

Read the relevant evidence files if [client] mentions supporting material or if the idea file references the evidence folder.

Do not read the ideas directory during normal coaching sessions. This command is the explicit trigger.
