# Ideas

[client]'s private idea space. Raw, half-formed, or fully developed — anything goes here.

## Convention

- One file per idea. Name it descriptively: `skill-marketplace.md`, `meeting-recording-governance.md`, etc.
- No required structure. Write however you think.
- Marty does NOT read this directory during session start or coaching. Marty only accesses ideas
  when [client] explicitly asks (e.g., "look at my idea about X" or invokes `/marty-refine-idea`).
- Ideas that graduate to actionable work may become missions, open threads, or feed into existing
  mission context.

**Privacy:** everything here except this README is gitignored and stays on your machine.
